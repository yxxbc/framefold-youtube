# Changelog

## 0.1.0

First public preview for Chrome and Edge.

- Fixed, compact toolbar and equal-width recommendation cards on Home.
- Shared desktop shortcuts and a collapsible navigation drawer.
- Wide watch layout with details and related videos below the player, plus creator details beside Shorts.
- Responsive thumbnail cards on the search page.
- Light, dark, and follow-YouTube themes, a glass toggle, and five local WebGL backgrounds.
- Appearance controls in the popup and temporary opt-out via `?margin=off`.
